# 📦 Dockerized Django + PostgreSQL + Nginx

Цей проєкт демонструє базову конфігурацію вебзастосунку на **Django**,
що працює у зв'язці з **PostgreSQL** та **Nginx**, повністю
контейнеризованих за допомогою **Docker** і **Docker Compose**.

## 🏗️ Склад проєкту

Проєкт складається з трьох сервісів:

- **web** --- Django-застосунок
- **db** --- база даних PostgreSQL
- **nginx** --- вебсервер, що приймає HTTP-запити і проксіює їх до
  Django
